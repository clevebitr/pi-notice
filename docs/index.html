pi-notice · Localization

Notifications, /notice output, and the TUI settings panel are translated. Help us add your language.

Shipped languages

  • English 151 / 151 strings · base language en
  • 简体中文 151 / 151 strings zh-CN
  • 繁體中文 151 / 151 strings zh-TW

Choose the language

# environment
PI_NOTICE_LOCALE=zh-TW pi

# config file (~/.pi/agent/pi-notice.json or <project>/.pi/pi-notice.json)
{ "locale": "zh-TW" }

# inside pi
/notice locale zh-TW
/notice            # TUI panel → Language

Contribute

WayBest for
Weblate Translating in a browser; results arrive as pull requests.
locales/ Editing JSON directly, or adding a brand new language.

Rules that matter

Keys are flat with dots (notice.settled.done). Keep every {placeholder} intact; CI compares them with English. Missing keys fall back to English instead of breaking a notification. Keys ending in .one are optional English plurals and may be omitted.

Verify locally

npm run check:locales   # coverage table, key + placeholder parity
npm test
